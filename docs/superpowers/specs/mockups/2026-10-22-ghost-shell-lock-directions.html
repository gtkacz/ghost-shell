GHOST-SHELL · PROJECT 2 · LOCK + LOGIN

Three directions for the password box

Each is the same thing for lock (Meta+L, wake from sleep) and login (after boot); flip between them with the toggle. They all use the shell's own language: Kode Mono, the dot grid, scanlines, chamfered panels with Grid brackets, segmented cells, and colour only when something needs you. Click a frame, then type: every character lights one cell (the length is visible, the characters never are). Enter with anything other than ghost shows the failure; ghost plays the scan pass that would hand over to the greeting. Caps Lock shows a warn chip; the US/BR chip flips the keyboard layout.
