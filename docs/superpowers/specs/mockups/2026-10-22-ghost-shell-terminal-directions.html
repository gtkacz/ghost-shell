GHOST-SHELL // TERMINAL

Where does the terminal sit relative to the desktop?

The desktop is a HUD: dot grid, scanlines, hairline panels, Japanese tags, translucent glass. A terminal is where you work, so each direction below keeps the palette and font but drops a different amount of the HUD vocabulary. All three are shown on a stand-in desktop so the contrast is visible. Same prompt content in each: a Starship prompt, a git and eza listing, a failing test (crit), an atuin/autosuggestion ghost, and a selection.

BARE TTY

Strips the HUD: no dots, no scanlines, near-black solid ground, one signal-coloured edge. Chrome collapses into a single status line at the bottom (tmux-like) that carries the Japanese tag and system info.
