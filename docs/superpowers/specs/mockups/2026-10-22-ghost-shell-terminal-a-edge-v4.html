GHOST-SHELL // TERMINAL

Full-spectrum palette, same quiet chrome

The desktop stays teal, amber and red because it is a status display. The terminal gets a full eight-hue ANSI set at a shared lightness so nothing is too dark to read (your blue dates on black are the cautionary case). Red is reserved for failure, so write bits and similar "danger-looking" tokens use orange instead. Teal remains the accent: cursor, prompt, frame edge.
