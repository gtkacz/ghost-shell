GHOST-SHELL // TERMINAL

Regular versus bold, in three fonts

Each window shows the cases where weight matters: the path chip, a directory next to files, and a failed command. Directories are bold and underlined here, and the failure uses ✗ (a proposal), so weight is no longer the only cue. Kode Mono is limited to 400 and 700; the other two use 300 regular and 800 bold. Compare the gap between a bold and a regular line in each.
