# ghost-shell audit, 2026-10-26

A whole-repo audit at HEAD `0d0e11a`, read-only. Load assumed: one user, one machine, daemon and shell running for weeks without a restart, any local app able to send notifications at any rate. Both test suites passed at the time (684 node tests, the whole Cargo workspace).

Line numbers are those of `0d0e11a`. The plan that fixes these is `docs/superpowers/plans/2026-10-26-ghost-shell-audit-fixes.md`.

## Must fix

1. **Restore throws away config changed since the retire** (`scripts/plasma-panel.sh:489-502`, `scripts/plasma-notifications.sh:198-210`). `restore` copies the pre-retire Plasma files over the live ones without saving the live ones first. Everything the user changed in Plasma after the retire is lost.
2. **Unread critical notifications never leave the history** (`crates/ghostd/src/feeds/notifications/history.rs:247-262`). `enforce` exempts unread criticals from `history_limit`; nothing marks them read, so one app sending criticals grows memory, disk writes and every publish without bound.
3. **No size cap on a notification's text or actions** (`crates/ghostd/src/feeds/notifications/server.rs:144-198`). A 100 MB body is kept four times, re-saved and re-sent on every change until evicted.
4. **A stuck collector freezes every sampled topic and systemd never notices** (`crates/ghostd/src/server/sampling.rs:91-101`, `crates/ghostd/src/collect/disk.rs:164-174`). The blocking tick is awaited with no deadline; `statvfs` on the FUSE NTFS mount or an NVML call can hang it. The socket stays open, so `Restart=on-failure` never fires.
5. **Lock-screen package deleted before its replacement is built** (`scripts/install.sh:322-326`). A failed copy leaves KWin's drop-in pointing at a half-built package.
6. **A missing end marker truncates `.zshrc`** (`scripts/install-term.sh:52-75`). The awk skips to the end of the file when the end marker was hand-deleted.
7. **Transient replace creates a new toast each time** (`history.rs:207-211`). OSDs send transient plus `replaces_id` per key press; each gets a new id, and two presses within a second return `ExcessNotificationGeneration`.
8. **`image-path` gets a doubled or wrong `file://`** (`shell/host/Toast.qml:206`). `file:///x.png` and icon names like `mail-unread` become unloadable URLs and hide the app icon.

## Should fix

9. **Every real Claude session file fails to parse** (`crates/ghostd/src/feeds/agents/claude.rs:26-27`). Live files write `procStart` as a string; the struct wants `u64`. Fixtures use a number, so no test fails.
10. **A replaced notification never toasts again** (`shell/kit/GhostKit/lib/notifications.mjs:23-24`, `shell/host/Toasts.qml:70-75`). Eligibility is keyed by id only; the daemon bumps `revision` and keeps `arrived_s`.
11. **Expired and evicted notifications never send `NotificationClosed`** (`state.rs:475-482`). `EXPIRED` is used only by a test assertion; `notify-send -w` with a transient blocks forever.
12. **A config error stays shown after the file is fixed back to its old content** (`crates/ghostd/src/config/watch.rs:163-171`). `publish_if_changed` skips a config equal to the live one, so nothing clears the pinned error.
13. **Transient-notification PNGs are never pruned** (`state.rs:266-275`, `images.rs:17`). Pruning runs only inside a save, which transients never trigger; `MAX_PIXELS` allows 16.7 M pixels per image.
14. **`recent` calls `stat` on the single runtime thread** (`crates/ghostd/src/feeds/recent.rs:107-111`). One recent file on a hung mount blocks the whole daemon.
15. **A refused pin is swallowed** (`crates/ghostd/src/feeds/pins.rs:63-65`). Only a `warn!`; the user sees nothing.
16. **Markup stripping eats real text** (`markup.rs:22-25,57-75`). `From Bob <bob@x.com>` loses the address in body, body_text, history and search.
17. **`gate.ini` is rewritten with two fsyncs on every signal change, on the runtime thread** (`crates/ghostd/src/gate.rs:122-141`).
18. **Terminal backup skips configs outside `$HOME`** (`scripts/term-backup.sh:14-28`). With `XDG_CONFIG_HOME=/mnt/cfg` the configs are overwritten with no backup.

## Nice to have

19. **Spectrum publishes identical frames 30 times a second during silence** (`crates/ghostd/src/feeds/spectrum/mod.rs:118-123`).
20. **Dead and duplicate code**: `launcher.style` (`crates/ghost-proto/src/config.rs:420-451`, read by nothing), `next_topic` (`feeds/mod.rs:107-118`, test-only), `ConfigFeed::current`, `SizeHints`, `server::release`, `Outcome.replaced`, `tickerText`, `quietSince`'s own padding, three one-caller wrappers in `collect/labels.rs`, duplicated `require_tools`/`require_shaders` bodies in `install.sh:97-117`, and `sky.rs:207-239` calendar maths plus an `unsafe localtime_r` that jiff provides.

## Smaller items

21. `take_id` hands out `u32::MAX` once and then wraps to 1 without checking that the id is free (`history.rs:241-245`); a saved `u32::MAX` makes `from_json` refuse the whole file.
22. `is_public_v4` misses 198.18.0.0/15, 192.0.0.0/24 and 240.0.0.0/4 (`uplink/sockets.rs:131-140`), so they count in "N shown of M" and never draw.
23. The HTTP agents follow redirects to plain `http` (`feeds/http.rs:27-36`, `ghost-alerts-inmet/src/main.rs:141-145`); `fetch-geoip.sh` has no `--max-time`, `--fail` or `--proto-redir`.
24. CPU core and CCD loads go stale when SMT is toggled at runtime (`collect/cpu.rs:284-352`): offline threads stay members and average in as 0.
25. `agents::watch` busy-loops if the notify thread dies (`feeds/agents/mod.rs:191-202`); `recv()` returning `None` is not handled as it is in `watch_usage`.
26. A widget manifest default is never checked against its declared type (`widgets/manifest.rs:245-260`); `type="int" default="3"` ships a wrong-typed slot with no error.
27. `State::topic` publishes on every `windows` update even when `fullscreen` did not change (`state.rs:160-209`).
28. `Toasts.qml` keeps `shownIds`, `announced` and `endedIds` for ever, and copies `shownIds` on every toast.
29. `make smoke` and `measure-covered.sh` run the shell on the caller's compositor; only the bus is private (`scripts/qml-smoke.sh:669`, `scripts/measure-covered.sh:206`).
30. Kode Mono is fetched from the `main` branch with no checksum (`scripts/install.sh:74-79,152-169`).
31. NetworkManager rules do not watch `Device.Ip4Config` or `Connection.Active.Ip4Config` (`feeds/links/nm.rs:160-173`), so a DHCP address change mid-lease stays stale.
32. `RUST_LOG` is ignored: `tracing_subscriber::fmt()` with no filter, INFO fixed (`main.rs:133-136`).

## Not checked

QML widgets beyond tasks, launcher-tile, notifications and media; `Gallery`, `GreetingScreen`, `Dock`, `PerfOverlay`, `NotificationCentre`; SDDM and lock QML; the fake feeds; `spikes/`; test bodies (names only); real-hardware hang likelihood for 4 and 14; live INMET and NetworkManager behaviour.
